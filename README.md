# ইনভেন্টরি ও হিসাব সফটওয়্যার

ফার্মেসি, গ্রোসারি ও রেস্টুরেন্টের জন্য একটাই সিস্টেম: একটা কোর, আর দোকানের ধরন অনুযায়ী মডিউল।

## ফোল্ডার

- `schema.sql`: PostgreSQL স্কিমা (স্টক লেজার, FEFO ফাংশন, ভিউ)। এখনো চালিয়ে পরীক্ষা করা হয়নি।
- `prototypes/`: তিনটা ব্রাউজার প্রোটোটাইপ (নমুনা ডাটা, ডাটা শুধু ব্রাউজারে থাকে)
  - `pharmacy-inventory.html`: ব্যাচ, মেয়াদ, FEFO, স্ট্রিপ ভেঙে পিস, রোল (PIN ১২৩৪)
  - `grocery-inventory.html`: কেজি ও গ্রামে বিক্রি
  - `restaurant-inventory.html`: রেসিপি, উপকরণ নিজে থেকে কমা, অপচয়

## মূল সিদ্ধান্ত

1. একটাই সিস্টেম, দোকানের ধরন অনুযায়ী মডিউল
2. স্টক সরাসরি বদলায় না। প্রতিটা নড়াচড়া `stock_movements`-এ একটা লাইন, যা বদলানো বা মোছা যায় না
3. স্টক ও দাম ছোট একককে (পিস, গ্রাম, মিলি) রাখা হয়
4. কেনা ও বিক্রির দাম ব্যাচের সঙ্গে থাকে
5. অফলাইন বিল `sales.client_uuid` দিয়ে দুবার জমা হওয়া আটকায়
6. PWA, PostgreSQL, প্রতিজন ইউজারের নিজের লগইন
